วิธีกู้คืนเว็บ English Adventure

1. เปิดรีโป GitHub ของเว็บภาษาอังกฤษ (ตรวจชื่อรีโปให้แน่ใจก่อน ไม่ใช่รีโปอุ่นใจ)
2. ที่หน้าแรกของรีโป เลือก Add file → Upload files
3. แตก ZIP แล้วอัปโหลด index.html และ sw.js ทับไฟล์ชื่อเดียวกันที่หน้าแรก
4. กด Commit changes
5. รอเว็บอัปเดต แล้วปิดแอปเดิม เปิดเว็บภาษาอังกฤษจาก Chrome ใหม่และรีเฟรช

ถ้ามีไฟล์ luck-*.webp หรือโฟลเดอร์ backend-worker ที่เพิ่มมาจากชุดอุ่นใจ สามารถลบออกจากรีโปภาษาอังกฤษภายหลังได้ หน้าเว็บอังกฤษจะไม่เรียกใช้ไฟล์เหล่านั้น
